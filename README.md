# Synthetic Voting for the 2026 U.S. Senate Midterm Elections

A forecast of all 35 U.S. Senate races on 3 November 2026 (33 regular elections and the Florida
and Ohio specials) from **synthetic voters**: personas drawn from validated voters in the 2024
Cooperative Election Study (CES), whose vote is generated by four large language models and then
combined with state polls. **No real person was surveyed.**

- **Website:** <https://mh2244.github.io/US_Midterms_Synthetic_Voting/>
- **Authors:** Jingxuan (Amelia) Feng, Maggie Huang, Kexin (Coco) Liu
- **Licence:** MIT ([`LICENSE`](LICENSE))

**Final forecast (31 October):** Republicans keep control of the Senate in 37% of 4,000
simulations; the median outcome is 52 seats for the Democratic caucus and 48 for Republicans
(90% interval for Republicans: 40 to 55).

## Method in brief

1. **Personas.** 100 validated 2024 voters per state, drawn from the CES with probability
   proportional to the weight `vvweight_post` and described by age, gender, race, education,
   income, ideology and party identification. Their 2024 vote is not in the prompt.
2. **News.** On 27, 29 and 31 October each persona receives nine short news paragraphs from ten
   outlets; a run without news (`nonews`) is the baseline.
3. **Answers.** Four models from four companies answer each persona three times in free text,
   through OpenRouter: 42,000 answers per run.
4. **Scoring.** Semantic Similarity Rating (SSR) turns each answer into probabilities for the
   left candidate, the Republican and "other".
5. **Combining with polls.** Each model's average gap from the polls (a Republican lean of 5 to 9
   points) is subtracted, and the corrected share is averaged with the state's poll average, or
   with the 2024 result plus a uniform swing in the 10 unpolled states, by inverse-variance
   weights.
6. **Simulation.** 1,000 draws per state and model, with persona, model and poll error and a
   national error (standard deviation 0.03) shared by all states; the four models count equally.

The website also reports the synthetic voters alone, the forecast without the bias correction
(42%), a forecast with no language model (34%), the effect of the news, the sensitivity to the
assumed errors and a comparison with PredictIt.

## Reproducing the forecast

### Setup

Use Python 3.12 and [Quarto](https://quarto.org) 1.9.

```bash
python3 -m venv .venv && source .venv/bin/activate
python -m pip install -r requirements.txt
```

Model calls need an OpenRouter key in a local `.env` file, which is in `.gitignore`:

```dotenv
OPENROUTER_API_KEY=your_key_here
```

GitHub Actions reads the same name from a repository secret. Shared settings (models, sample
sizes, seed, paths, colours) are in [`scripts/config.py`](scripts/config.py); every random step
uses seed 2026.

### Data

| Data | Source | Script | Saved to |
|---|---|---|---|
| 2024 CES | [Harvard Dataverse](https://dataverse.harvard.edu/) | `02`, `03` | extract in `data/02-analysis_data/` |
| Senate polls | [PollResults API](https://pollresults.org/api/) | `02d`, `03b` | `data/01-raw_data/polls/`, cleaned in `data/02-analysis_data/polls/` |
| Candidates | [Wikipedia](https://en.wikipedia.org/wiki/2026_United_States_Senate_elections) | `05`, `06` | `data/01-raw_data/`, nominees in `data/02-analysis_data/` |
| News | RSS/Atom feeds of ten outlets, Google News | `04`, `04b` | `data/01-raw_data/news/`, screened in `data/02-analysis_data/news/` |
| Prediction-market prices | [PredictIt](https://www.predictit.org) public API (non-commercial use) | `02c` | `data/01-raw_data/markets/` |
| Seats not up in 2026 | Wikipedia, entered by hand | – | `data/01-raw_data/` |
| State boundaries | public GeoJSON | `02b` | `data/01-raw_data/us-states.json` |

**The raw CES file is not in the repository.** It is large and distributed under Harvard
Dataverse's terms of use. Download it with

```bash
python scripts/02-download_ces.py get --file-id 12050325
```

or by hand (2024 CES Common Content), and save it as
`data/01-raw_data/ces/CCES24_Common_OUTPUT_vv_topost_final.csv`. Script `03` reduces it to
`data/02-analysis_data/ces2024_senate_demographics.csv`, which is committed and is all that later
scripts read, so the pipeline runs from script `07` without the raw file.

### Running

Every step works on the run set by `RUN` (`2026-10-27`, `2026-10-29`, `2026-10-31` or `nonews`)
and writes to that run's folders, so runs never overwrite each other.

```bash
export RUN=2026-10-31
python scripts/02d-download_polls.py
python scripts/03b-clean_polls.py
python scripts/04-collect_news.py && python scripts/04b-assign_news.py
python scripts/08-build_prompts.py --news
python scripts/09-query_models.py --batch-size 40 --sleep 0   # paid: 42,000 calls, about US$8
python scripts/10-score_responses.py
python scripts/11-build_forecast.py --combine none            # synthetic voters only
python scripts/11-build_forecast.py --bias keep               # comparison: bias not removed
python scripts/11-build_forecast.py                           # headline, run last
python scripts/12-test_actual_data.py
for s in 13-plot_state_dotplot 13b-make_map 15-plot_win_probabilities 15b-make_headline 15c-make_battlegrounds_and_seats \
         16-make_crosstabs 16b-compare_runs 16c-make_sensitivity_table 16d-make_cost_table 16e-make_news_tables \
         02c-download_predictit 16f-compare_markets 17-publish_latest; do python scripts/$s.py; done
quarto render
```

For the baseline, set `RUN=nonews`, skip `04` and `04b`, and run `08` without `--news`. Script
`09` saves answers as it goes, so an interrupted run resumes when rerun. Each script begins with
a preamble on its inputs and outputs; [`scripts/README_PIPELINE.md`](scripts/README_PIPELINE.md)
gives more detail.

| Stage | Scripts |
|---|---|
| Simulated data and its tests | `00-simulate_data`, `01-test_simulated_data` |

| Cleaning | `03-extract_ces`, `03b-clean_polls` |

| Figures | `13-plot_state_dotplot`, `13b-make_map`, `14-plot_sample_composition`, `15-plot_win_probabilities`, `15b-make_headline`, `15c-make_battlegrounds_and_seats` |

## Tests

Two pytest and pandera suites share the schemas in `scripts/schemas.py`: 33 tests on the
simulated data and 63 on each real run.

```bash
python -m pytest scripts/01-test_simulated_data.py
RUN=2026-10-31 python -m pytest scripts/12-test_actual_data.py
```

They check that every prompt reached every model three times; that failed or empty answers stay
below 10% per model and remain missing rather than becoming zeros; that answers came from the
requested provider; that probabilities lie between 0 and 1 and sum to 1; that the two shares in a
race sum to 1 and the winner has the larger one; that each combined share lies between its two
inputs and matches the recorded weights; and that every simulation fills 100 seats. Each test
has a docstring explaining why. On GitHub Actions a failed test stops publication.

## Corrections and known issues

- **Montana.** Script `06` picked the Democrat Alani Bankhead as the left candidate, but the main
  challenger is the independent Seth Bodnar (polls: Alme 42, Bodnar 31, Bankhead 16). This was
  fixed before the 31 October run. Montana's 27 and 29 October results are kept as run and are
  left out of the news and PredictIt comparisons for those days. For the same reason the test
  `test_prompt_names_both_candidates` fails on the 27 and 29 October prompts.
- **Bias correction.** A revision on 1 November rebuilt the forecasts without the bias
  correction. We kept the bias-corrected forecast of the scheduled runs as the headline; the
  other version is reproducible with `--bias keep` and reported in the method table.

## Models

All are reached through OpenRouter, and the id that answered is saved with each answer.

| Purpose | Model | Settings |
|---|---|---|
| News screening (`04`) | `openai/gpt-4.1-nano` | temperature 0.1 |
| Voting answers (`09`) | `anthropic/claude-haiku-5.5`, `openai/gpt-6-luna`, `deepseek/deepseek-v4.1-flash`, `google/gemini-3.5-flash-lite` | default temperature, at most 800 tokens, reasoning off (Gemini: minimal, as required) |
| SSR embeddings (`10`) | `google/gemini-embedding-2` | SSR softmax temperature 0.25 |

Pilots used free models (`poolside/laguna-s-2.1:free`, `nvidia/nemotron-3-ultra-550b-a55b:free`,
`dots-studio/dots-3-note-preview:free`) and the local embedder `all-MiniLM-L6-v2`; none of their
answers enter the forecast.

## Website design

One page, [`index.qmd`](index.qmd), rendered to `docs/`. Results are included from
